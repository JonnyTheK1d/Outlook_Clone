## Scope

Marketing landing page for the Postblick Windows desktop app, `website/index.html`, static HTML/CSS/JS, served by GitHub Pages or from disk. Visitor mode: Persuade.

## Audience and action

Private Windows 10/11 users who want an Outlook-like mail app for their own accounts and care that their data stays on their PC. Action: download the Windows installer (direct link to the published release EXE), secondary: view the source on GitHub. Proof: real app screenshots from the browser demo (labelled as demo data), real checksums and test counts from docs/validation.md, real feature list from docs/feature-status.md, honest limitations. Constraints: German, informal du; must state that Postblick is not a Microsoft product; no invented users, ratings, press, prices or certifications.
